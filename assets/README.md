# 에셋

Claude Office 는 외부 에셋 없이 **코드로 그린 기본 타일**로 동작해요. 다른 타일셋을 쓰고 싶을 때만 이 폴더를 쓰세요.

## 재배포가 안 되는 타일셋 넣기 (예: 유료·비상업 라이선스 팩)

1. 팩을 직접 내려받아 16px 타일만 가로 한 줄로 이어 붙인 `assets/third-party/tileset.png` 를 만들어요.
2. 같은 폴더에 `tileset.map.json` 을 만들어 **게임 타일 이름 → 몇 번째 타일인지** 적어요:
   ```json
   { "WOOD": 0, "SHELF": 1, "PLANT": 2, "CHAIR": 3, "BED_TOP": 4, "BED_BOT": 5 }
   ```
   쓸 수 있는 이름은 `web/src/map/defaultMap.ts` 의 `G` 목록이에요. 적지 않은 타일은 기본 그림이 그대로 쓰여요.
3. 새로고침하면 적용돼요. 파일이 없거나 깨져 있으면 자동으로 기본 그림으로 돌아가요.

`assets/third-party/` 는 `.gitignore` 에 들어 있어서 저장소에 올라가지 않아요. 각 팩의 라이선스(출처 표기, 비상업 여부 등)는 직접 지켜 주세요.

## 저장소에 에셋을 추가하려면

CC0 등 **재배포 가능한** 에셋만 올리고, `CREDITS.md` 에 출처·작성자·라이선스를 적어 주세요.
특정 게임 캐릭터나 브랜드 마스코트를 닮은 그림, 게임에서 추출한 그림은 받지 않아요.
